# Gwenda ops

Internal tools and Workers for bar operations.

| Package | Role |
|---------|------|
| [`site/`](site/) | Password-gated HTML tools on Cloudflare Pages ([gwenda-ops.pages.dev](https://gwenda-ops.pages.dev)) |

| [`recipe-cost-webhook/`](recipe-cost-webhook/) | ClickUp recipe cost Worker |

Pages app setup, Baserow menu recipes, and password secrets: see [`site/README.md`](site/README.md).
