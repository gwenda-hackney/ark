Full name = supplier / menu product name. POS = short till label (serve in brackets). Click a row to expand the recipe. Use Copy next to the full name, or click the POS column for the till label.

Cost = ingredient / serve cost. Target = price at industry pour (cocktails 20%, beer 22%, softs 25%). Actual = menu sell price. Δ £ = actual − target (positive = dearer than target). Δ pp = actual pour % − industry pour % (positive = worse margin). Weight = relative expected sales mix for weighted averages — not a sell price. Higher weight = more of this drink in a typical week. POS labels are plain: drink + serve, e.g. Lippa (Pint), 4.8 (Half), Botanic NA (BTL), Coke (Pint). Spirits & digestivi: base pour in the POS name (25ml spirits/digestivi, 50ml vermouth aperitivo where that is the house serve, 75ml Martini Rosso, 50ml Vin Santo). Expand a row for Double 50ml sell (~1.6× soft Wick — e.g. Jameson £5.50 → £9). Straight ×2 kept only as an unused alternate. Jameson double also has its own POS row at £9.
